# Content provenance

Open Kitchen Toolkit is original MIT-licensed code and skill content. The public capability names of an existing kitchen instruction service informed coverage requirements. The research workspace separately inspected that service's accessible instructions and public scripts for evaluation. We do not claim that nobody on this project ever saw competitor material, or that its private backend was recovered.

The73 released skill bodies were authored independently from public use-case titles, our existing original skills and synthetic examples. The library author was instructed not to read private competitor snapshots or reference instruction files. Released content must not copy proprietary prompts, distinctive templates, house rules, branding or private materials. Code implements transparent calculations rather than reconstructed competitor source.

Private vendor snapshots, original vendor outputs, authenticated connector details and Cheezies source records stay outside this package. Release scripts use an explicit file allowlist. Comparison evidence contains hashes, original summaries and numerical observations, not vendor instruction bodies.

All included restaurant names, people, figures and incidents are synthetic illustrative inputs, not endorsements or verified facility facts. Worked-example reviews and automated validation do not certify food safety, employment decisions, tax treatment or real supplier prices.

Native AI-client acceptance, hosted checks, local tests and real kitchen trials are recorded separately. MIT does not change an external AI provider's fees or account terms.
