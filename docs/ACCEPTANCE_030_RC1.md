# CulinaryOS Interagency 0.3.0-rc.1

This is a standalone release candidate for public testing, not final production acceptance. Existing machine/plugin identity is preserved. Live CulinaryOS authorization is deferred and disabled; no platform migration or resident-data integration is part of this release.

## Delivered

- 118 canonical workflows, 24 starter journeys, and 21 public stateless tools.
- Role-aware help for nine roles, eight establishment types and five actions across 14 task areas. Discovery uses disclosed shared-word matching, not semantic classification.
- Six reference records with publisher, jurisdiction, retrieval date, unresolved revision and reuse notes; 42 original representative questions. No statistical popularity claim or bundled third-party manuals.
- Three deterministic business calculators, four text-only menu templates and reviewed print/HTML export. Operational-report boilerplates retain unknown observations and blank signatures.
- Per-area partial capability labels, per-workflow guidance-only status, honest general-AI fallback and uninstalled skill-draft boundaries.

## Open gates and limitations

- Full host/model output trials, paired vendor benchmarks, ROI and clinical suitability are NOT VERIFIED. Passing software checks does not establish these.
- Fresh native ChatGPT, Claude, Gemini CLI, Cursor and Codex model-execution/installation acceptance remains UNVERIFIED for this candidate. Supplied adapters and reference SDK results are different evidence.
- Manual playbooks offer guidance without live calculation or automation. Consumer Gemini website support is not claimed.
- Menu editor drafts are not persisted on navigation. Download reviewed output before leaving. Browser print produces PDF; the formatter itself returns HTML/plain text.
- Public tools never save restaurant records, submit forms, place orders, send messages, publish marketing or install skills. Narrative drafting occurs in the selected AI host. Local records require the explicit private workspace.
- Reference links are not live research; verify current editions and local applicability. General safety sources do not establish approved clinical diets.

## Reproduce and rollback

Run `npm ci`, `npm run typecheck`, `npm run build`, `npm test`, `npm run check:scenarios`, `npm run test:release`, `npm run package`, and the package smoke scripts. Browser scripts require installed Chrome and Playwright Core and an explicitly chosen loopback synthetic workspace.

Retain v0.2.4 as the previous stable download. Hosted rollback target is the previously verified stateless deployment `5cb713fa-2c47-4036-9127-c762d996c817`. Candidate hosting and publication receipts are recorded separately after those actions are verified.
