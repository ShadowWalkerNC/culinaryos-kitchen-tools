# Release readiness0.2.0

This is a development release of Open Kitchen Toolkit. Skills and software are MIT licensed; no toolkit subscription or extra login. AI providers and infrastructure can charge separately. Public hosting carries no unlimited-service guarantee.

Public download/source publication, hosted deployment, private creator-plugin update, native AI-client installation and public directory review are separate gates. See ACCEPTANCE.md for actual results rather than interpreting this file as a certification.

The existing plugin identity and private audience are preserved. Public community packages are separate GitHub release assets. A public directory submission is deferred until publisher identity, listing, support/privacy/terms, demo and review requirements are supplied and verified. Downloadable source/installers do not require directory approval.

CulinaryOS live API integration, real kitchen trials, current supplier invoices, local legal/safety approval and external action integrations remain outside this release. No background model provider is configured.

The Railway CLI reports railway.toml retirement2026-12-01. Migrate deployment configuration before that date; existing deployment is reused now rather than provisioning a parallel service.
